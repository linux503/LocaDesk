LocaDesk 是 Mac 端 iPhone 定位模拟工具：搜索城市、地图点选、一键推送到手机， 支持 USB / 同一 Wi‑Fi，中英双语。源码不公开，发布包与版本信息在这里更新。

核心能力

只做定位模拟该做的事，不堆花活。

地图选点

搜索城市 / 地址 / 经纬度，或直接点地图，坐标一目了然。

一键模拟

开始模拟、更新到此处、恢复真实位置，流程清晰。

无线连接

USB 信任一次后，同一 Wi‑Fi 可继续使用（需开发者模式）。

收藏历史

常用地点收藏，最近使用可回看，测试更省事。

在线更新

设置里检查更新，自动对比官网 version.json。

中英界面

默认中文，设置一键切换 English。

界面预览

窄窗口也能舒服用，接近手机竖屏比例。

快速开始

第一次使用建议按下面顺序走一遍。

1
安装工具

终端执行：pip3 install -U pymobiledevice3

2
开启开发者模式

iPhone：设置 → 隐私与安全性 → 开发者模式（开启后重启确认）。

3
USB 连接并信任

解锁手机，点「信任此电脑」。需要无线时保持同一 Wi‑Fi，并允许「本地网络」。

4
开始模拟

打开 LocaDesk → 选点 → 开始模拟位置。退出时可自动恢复真实定位。
